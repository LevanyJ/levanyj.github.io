# 作品集内容映射与阶段边界

| 阶段 | 课程日期 | 主要学习主题 | 对外展示方式 |
|---|---|---|---|
| Python 基础 | Day 01–06 | 变量、条件、循环、列表字典、函数、程序状态 | 知识库 + 少量练习脚本 |
| 数据采集 | Day 07–12 | 静态 HTML、XPath、章节文本、API、POST、视频平台结构 | 知识库 + 经过筛选的源码 |
| 自动化与应用 | Day 13–18 | 浏览器自动化、CSV、业务数据、Cookie、线程、请求分析 | 案例描述 + 非敏感代码 |
| 数据分析 | Day 19–22 | 考研院校数据、Pyecharts、模拟薪资大屏、贝壳二手房 | 项目详情 + 处理示例 + 浏览器 CSV Lab |
| Git 与交付 | Day 23–24 | 仓库管理、GitHub Pages、作品集、简历、TRAE 工具 | 公开网站 + 24天索引 + README |

## 六个精选项目

1. Day 22：二手房数据采集与整理。
2. Day 15：程序员自由职业需求关键词采集。
3. Day 20–21：CSV 数据工作台（作品集新增交互演示）。
4. Day 19–20：院校数据清洗与可视化。
5. Day 24：六合一 Python/Tkinter 桌面应用代码组。
6. Day 13–18：浏览器自动化与线程/调度概念。
